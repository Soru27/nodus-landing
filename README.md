# NODUS Intelligence — Landing

Landing page statica per [NODUS Intelligence](https://github.com/Soru27/nodus-publica) — analisi degli appalti ICT della PA lombarda basata su dati pubblici ANAC.

**Status**: fase pilota, zero clienti.
**Contact**: [Jeffrey Minaya su LinkedIn](https://www.linkedin.com/in/jeffrey-m-b503761b2)

## Deploy

Pure HTML/CSS statico. Servibile su qualsiasi static host:

- GitHub Pages (questo repo): Settings → Pages → Source: `main` / `(root)`
- Netlify Drop, Vercel, Cloudflare Pages — analoghi.

## Stack

- HTML5, CSS3 vanilla. Nessuna dipendenza JS.
- Numeri verificati dal database NODUS al momento dell'aggiornamento (vedi `Numeri verificati — ultimo aggiornamento` in pagina).
